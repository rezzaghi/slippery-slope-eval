# Labeling rules

1. **Judge only the text.** A link counts as supported only if the argument itself gives the evidence, rule or mechanism. Real-world facts the argument doesn't state don't count, even if true.
2. **Common knowledge needs no evidence.** Facts a typical adult knows without looking anything up (milk spoils when left out) count as support. Specialist or empirical claims (opioid dependence patterns) do not.
